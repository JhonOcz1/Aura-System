# Aura System

> Aplicación interactiva diseñada para optimizar la gestión de tutorías y colaboración académica, facilitando la conexión entre pares, la organización de sesiones de estudio y el seguimiento del rendimiento académico.

---


## Características Principales
* **Emparejamiento Inteligente:** Sistema para conectar tutores y estudiantes según áreas de conocimiento y disponibilidad horaria.
* **Gestión de Sesiones:** Programación, recordatorios y control de asistencia a tutorías académicas.
* **Panel de Estadísticas y Progreso:** Visualización del rendimiento y reportes de actividad para los administradores del sistema.
* **Interfaz Fluida e Interactiva:** Experiencia de usuario optimizada para un uso ágil tanto en escritorios como en dispositivos móviles.
